# Security Policy

## Supported versions

Security fixes are targeted at the latest `main` branch version.

## Reporting a vulnerability

Do not post credentials, prompts containing private information, or exploitable details in a public issue.

Use **Security → Report a vulnerability** if private reporting is enabled. Otherwise, open a public issue without sensitive details to request private contact with the maintainer. Please include affected version and impact privately.

## Trust boundary

Research results, retrieved pages, and third-party prompts are untrusted inputs. Do not grant research subagents unnecessary filesystem, network, credential, or repository write access.
